# 第三方组件 / Third-party components

中文 · [English](#english)

本源码包包含原生 App 和项目自有的集成脚本。依赖另行安装：

- [FFmpeg](https://ffmpeg.org/)：许可取决于具体构建及其可选库。本包不分发 FFmpeg 二进制，也不提供代替其实际许可的通用声明。
- [MediaMTX](https://github.com/bluenviron/mediamtx)：单独下载的 Docker 镜像受其上游许可与声明约束。
- [Scrypted](https://github.com/koush/scrypted)：核心、插件及可选商业组件各自适用其条款。本项目不包含 Scrypted NVR，也不授予使用商业组件的权利。
- [Home Assistant](https://www.home-assistant.io/)：可选组件。
- Apple 框架由 macOS SDK 提供。Apple Home 和 HomeKit 属于 Apple 产品；本项目独立开发，未经 Apple 认证。

分发时请核对实际版本的上游声明。根目录 MIT 许可仅适用于本仓库原创代码与文档，不代替第三方许可。
